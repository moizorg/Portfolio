# Moiz Abdullah — Portfolio

A responsive personal portfolio website for Moiz Abdullah, a BS Computer Science student at UVAS Lahore focused on web development and data science.

## Features

- Responsive layout for desktop and mobile screens
- Light and dark theme switching with saved preference
- Mobile navigation menu
- Accessible skip link and semantic page sections
- One-click email address copying

## Project files

- `index.html` — page structure and content
- `styles.css` — all page styling, responsive rules, and themes
- `script.js` — navigation, theme switching, and copy-email interactions
- `img.png` — portfolio image asset

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static web server:

```powershell
python -m http.server
```

Then visit `http://localhost:8000`.

## Deployment

This is a static website and can be deployed with GitHub Pages, Netlify, Vercel, or any other static hosting provider.
